TastyDrop Backend

Backend API for TastyDrop, a full-stack gaming platform built with ASP.NET Core and MSSQL.

Portfolio project developed using ASP.NET Core, Dapper, SignalR and Microsoft SQL Server.

Provides business logic for inventory management, case opening mechanics, wheel spin, crash game, mines game, battle pass progression, user balances and item drop calculations.

Technologies

C#
ASP.NET Core Web API
Microsoft SQL Server
Dapper
JWT Authentication
SignalR

Features

User registration and authentication
JWT authorization
Inventory management
Case opening system
Upgrade system
Crash game
Balance management
Real-time notifications using SignalR
Mines game
Wheel spin
Battle pass progression

Architecture
The backend provides REST APIs for the Angular frontend and contains the main business logic of the application.

Main responsibilities:

Authentication and authorization
